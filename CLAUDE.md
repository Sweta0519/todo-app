# Todo App

A small single-page todo list app: add tasks, mark them done, delete them, and see how many are left. All data is saved in the browser.

## Stack

- Plain HTML, CSS, and JavaScript only
- No frameworks, no build step, no backend
- Data persisted in `localStorage`
- Deployed as a static site on GitHub Pages

## Running it

Open `index.html` directly in a browser. No server or build step needed.

## Rules

- Keep everything in the three files: `index.html`, `style.css`, `app.js`.
- Do not add any new libraries or frameworks without asking first.
- Do not add a backend, database, or build tooling.
